Versions
--------

1.0.2: 2026 November

 [*] Search bar: the results list no longer flickers or jumps back to the start when the index changes. A refresh with unchanged rows leaves the list alone, and a refresh with changed rows keeps the scroll position and the selected row.

1.0.1: 2026 November

 [+] Wildcards in name words: * matches any run of characters and ? one character, matched against the whole name, in addition to the existing syntax.

1.0.0: 2026 November

 [+] Name index of every fixed drive, built by a multi-threaded crawler on the NT directory API and saved to names.idx.
 [+] NTFS USN journal catch-up at startup and live change watcher.
 [+] Search bar with a global hotkey (Alt+Shift+Space, with fallbacks), ranked results, icons, filter chips and history.
 [+] Query syntax: name modifiers, path tokens, ext:, type:, kind:, in:, path:, size:, mtime:, re:, limit: and sort:.
 [+] Content index of text files under the content folders, with grep:, regex: and sym: content search.
 [+] Frecency ranking from opened and copied results.
 [+] Named pipe JSON lines API restricted to the current user.
 [+] sgcfs command line client: search, JSON output, stdio bridge, status, stop, show, install, uninstall and bench.
 [+] Tray icon with the index status, Folders dialog, Start at login and Open log.
 [+] Single instance: a second start shows the search bar of the running instance.
 [+] Per-user installer (Inno Setup) with Start at login and PATH options.
