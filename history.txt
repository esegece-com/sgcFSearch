 sgcFSearch

 [*] : Bug
 [+] : New
 [-] : Deleted

Versions
--------

1.0.5: 2026 November

 [+] Sort by directory: sort:dir and a Directory entry in the Sort chip order the results by folder path, then by name.
 [*] Search bar: the mouse wheel scrolls the results also when the focus is in the search box, as Windows 7 sends it. One notch moves one row with the default system setting, and high resolution wheels scroll smoothly.
 [*] Search bar: reopening it with no new text keeps the place in the list and the selected row.
 [*] Search bar: the scroll bar follows the list after a new search with the same number of rows.
 [*] Portable mode: the marker file wins over SGCFSEARCH_HOME, and sgcFSearch.portable.txt also counts as the marker.

1.0.4: 2026 November

 [+] Search bar: drag its empty area to move it. The position is remembered per monitor layout, and a double click on the empty area centers it again.
 [+] Search bar: a pin button keeps the bar open when it loses focus and lets other windows go over it.
 [+] Saved chip: save the current search under a name and apply it again from the chip menu.
 [+] Portable mode: a file named sgcFSearch.portable next to the exe keeps all the data in data\<computer name> next to it.
 [*] A failed save of the index at the end of the first crawl no longer stops the engine.

1.0.3: 2026 November

 [/] Content search (grep:, regex:, sym:) now ignores case by default. Before, a capital letter in the search text made it case sensitive.
 [+] case:yes and case:no filters choose the case of one content search. The pipe API grep request has the same option in its "case" field.
 [+] content_case setting in config.json: insensitive (default), smart (the previous behaviour) or sensitive. The setting is kept across updates.

1.0.2: 2026 November

 [*] Search bar: the results list no longer flickers or jumps back to the start when the index changes. A refresh with unchanged rows leaves the list alone, and a refresh with changed rows keeps the scroll position and the selected row.

1.0.1: 2026 November

 [+] Wildcards in name words: * matches any run of characters and ? one character, matched against the whole name, in addition to the existing syntax.

1.0.0: 2026 November

 [+] Name index of every fixed drive, built by a multi-threaded crawler on the NT directory API and saved to names.idx.
 [+] NTFS USN journal catch-up at startup and live change watcher.
 [+] Search bar with a global hotkey (Alt+Shift+Space, with fallbacks), ranked results, icons, filter chips and history.
 [+] Query syntax: name modifiers, path tokens, ext:, type:, kind:, in:, path:, size:, mtime:, re:, limit: and sort:.
 [+] Content index of text files under the content folders, with grep:, regex: and sym: content search.
 [+] Frecency ranking from opened and copied results.
 [+] Named pipe JSON lines API restricted to the current user.
 [+] sgcfs command line client: search, JSON output, stdio bridge, status, stop, show, install, uninstall and bench.
 [+] Tray icon with the index status, Folders dialog, Start at login and Open log.
 [+] Single instance: a second start shows the search bar of the running instance.
 [+] Per-user installer (Inno Setup) with Start at login and PATH options.
